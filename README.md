# 🛍️ Myntra Clone

A static frontend clone of the Myntra website, developed using **HTML**, **CSS**, and **Google Material Icons**. This project replicates the look and feel of Myntra's homepage for learning and portfolio purposes.

---

## 🔍 Features

- ✅ Responsive Header with Logo and Navigation Bar  
- ✅ Integrated Google Material Icons  
- ✅ Functional Search Bar (UI only)  
- ✅ Attractive Main Banner Section  
- ✅ Category Listings with Offer and Product Images  
- ✅ Footer Section with Useful Links  
- ✅ Clean, Modular Code Structure

---

## 🛠️ Tech Stack

- **HTML5**  
- **CSS3**  
- **Google Fonts & Material Symbols**
